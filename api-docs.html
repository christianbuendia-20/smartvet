GET /cliente/pagos/exito Callback: pago exitoso de Mercado Pago ▼

MP redirige aquí tras pago aprobado. Inserta un registro PagoCita con EstadoPago.COMPLETADO. Incluye verificación de idempotencia (no duplica si ya existe un pago COMPLETADO para la cita).

SmartVet 🐾

Sistema web de gestión veterinaria desarrollado con Java, Spring Boot y arquitectura MVC, orientado a la administración eficiente de clínicas veterinarias.

El sistema permite gestionar clientes, mascotas, veterinarios, citas médicas e historiales clínicos, aplicando buenas prácticas de desarrollo backend y organización empresarial.

🚀 Funcionalidades
Gestión de clientes
Registro y administración de mascotas
Programación y cancelación de citas
Gestión de veterinarios
Historial clínico veterinario
Sistema de autenticación y roles
Dashboard para clientes y veterinarios
Validación de formularios
Manejo de excepciones
Arquitectura MVC
